Tema do projeto

Aplicação web de Lista de Tarefas, onde o usuário organiza seus compromissos do dia a dia.

Resumo do problema

Muitas pessoas esquecem compromissos e atividades porque não têm um lugar simples para organizá-los. Esta aplicação resolve isso permitindo cadastrar, acompanhar e concluir tarefas em um só lugar.

Requisitos Funcionais
RF01 – O sistema deve permitir criar uma nova tarefa com título e descrição.
RF02 – O sistema deve permitir listar todas as tarefas cadastradas.
RF03 – O sistema deve permitir editar o título e a descrição de uma tarefa.
RF04 – O sistema deve permitir marcar uma tarefa como concluída ou pendente.
RF05 – O sistema deve permitir excluir uma tarefa.
RF06 – O sistema deve permitir filtrar as tarefas por status (todas, pendentes e concluídas).
Requisitos Não Funcionais
RNF01 – A interface deve ser simples e fácil de usar, mesmo para quem usa pela primeira vez.
RNF02 – O sistema deve funcionar nos principais navegadores (Chrome, Firefox e Edge).
RNF03 – O layout deve se adaptar a computadores e celulares (responsivo).
RNF04 – As operações (criar, editar, excluir) devem responder em até 2 segundos.
RNF05 – Os dados das tarefas devem ser salvos e não podem ser perdidos ao fechar a página.
RNF06 – O código deve ser organizado e versionado no GitHub.
